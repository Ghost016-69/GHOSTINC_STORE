About the shop

A store front built to be taken apart.

GHOSTINC is a portfolio project: a real catalogue, a real database and a real checkout flow, built without a framework, a bundler or a single dependency in the browser.

Two halves, cleanly split

The pages are plain HTML, CSS and JavaScript served by a static file server. Everything with a price on it comes from a Django REST API on its own port.

The front end

Seven pages, one stylesheet and four small scripts. No framework and no build step: the browser loads api.js, store.js, ui.js and main.js, and that is the whole application.

The back end

Django 6 with Django REST Framework and SQLite. The catalogue, promo codes, orders and stock all live in the database, and the Django admin is the shop manager.

The prices

The browser stores what is in your cart, never what it costs. Every total is re-quoted by the server, so a stale or edited cart cannot buy anything at the wrong price.

How the API works

Every endpoint the front end uses, mounted under /api/ on port 8000.

GHOSTINC REST endpoints
Method Path What it does
GET /api/products/ Search, filter, sort and page the catalogue
GET /api/products/<slug>/ One product, with specs and related items
GET /api/categories/ Categories with live product counts
GET /api/brands/ Brands with live product counts
POST /api/cart/price/ The authoritative cart total, VAT and delivery
POST /api/promo/validate/ Checks a promo code
POST /api/orders/ Places an order and reduces stock
GET /api/orders/<number>/ Looks an order up by its reference
POST /api/contact/ Logs a message from the contact page

Try it The API has a browsable interface. Open 127.0.0.1:8000/api/ while the back end is running.

Demo data, honest limits

The catalogue is seeded by a management command, so it is version controlled and reproducible rather than typed in by hand.

  • 30 products
  • 8 categories
  • 14 brands
  • 3 promo codes
  • VAT at 15%
  • Free delivery over R 2 500

What is not here. No payment gateway, no customer accounts, no live shipping rates and no real photography. Brands and prices are invented for the demo. Placing an order writes it to the local database so the flow can be demonstrated end to end.
